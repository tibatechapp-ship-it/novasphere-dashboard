# NovaSphere Dashboard

FastAPI + WebSockets + Cyberpunk real-time dashboard.

## Run

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8080
```

Open http://127.0.0.1:8080

## Features
- Real-time WebSocket metrics stream
- Cyberpunk neon UI
- Live agent status grid
- Event log
